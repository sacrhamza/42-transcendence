# Frontend documentation

SUF (Stack Under Flow) is a React frontend prototype for a developer community. These documents describe the implementation in this repository as of 2026-11-06.

- [Setup and build](SETUP.md): installation, local URLs, production build, hosting, and Git handoff.
- [Frontend implementation](FRONTEND.md): structure, routes, validation, storage, recent fixes, and verification.
- [Backend integration](BACKEND-INTEGRATION.md): existing connection points and services still needed.

Start with setup to run the UI. Read the backend integration guide before connecting account or community services. Example data and browser storage do not represent shared server data.
